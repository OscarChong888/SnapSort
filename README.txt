# Snap Sort PBL Website

A responsive static website for the Snap Sort Mobile App PBL Project.

## Files
- `index.html` — main website
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation and placeholder-link behavior
- `assets/` — put screenshots, QR codes, logos and other media here

## How to customise

1. Open `index.html`.
2. Replace the screenshot placeholders with your actual images.
3. Replace the demo placeholder with your YouTube/video embed.
4. Replace the project links and QR code.
5. Update the survey evidence numbers in the "Why It Matters" section.
6. Add your actual PBL documentation and references.
7. Test every link before publishing.

## Publishing with GitHub Pages
Create a GitHub repository, upload all files while keeping the folder structure, then enable GitHub Pages from the repository settings. The site is completely static, so no server is required.

## Important
Some wording is intentionally cautious around Edge AI, Firebase and future features. Update those parts to exactly match what your final Snap Sort implementation actually contains.
